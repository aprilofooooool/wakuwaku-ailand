# わくわく！あいランド

たまごっちのキャラクターといっしょに遊ぶ、子ども向けのミニゲーム集です。
インストールも通信も要りません。`index.html` を開くだけで遊べます。

> 個人が楽しむためのファン作品です。公式の画像やセリフは使っていません。画像は自作の仮絵です。

## ひらきかた

1. このフォルダの `index.html` をダブルクリックします。
2. ブラウザが開いて、入口ページ（ゲームのえらび画面）が出ます。
3. 遊びたいゲームのカードをタップします。どの画面も、上の「もどる」で入口にもどれます。

対局中のゲームは手ごとに自動で保存されます。入口からもう一度ひらくと「つづきから」で再開できます。

## 開発用コマンド

コマンドはすべて `scripts\run.bat` から実行します（Node.js が必要です。Python は使いません）。プロジェクトの外から実行するときは、先にこのフォルダへ移動します。

```
cd <このフォルダのパス>
scripts\run.bat test
```

| コマンド | 内容 |
|---|---|
| `scripts\run.bat test` | 自動テスト（`tests/test.html` に載っているテストを Node で実行） |
| `scripts\run.bat check` | 静的検査（外部通信・禁止パターン・参照切れ・ファイル名・`localStorage` の直接使用・`data-base` と画像の参照・テスト一覧の漏れ） |
| `scripts\run.bat serve` | 表示確認用の簡易サーバー（`http://127.0.0.1:8080/`） |
| `scripts\run.bat resize-images` | `assets-src/` の元画像から表示用の 512x512 画像を作る（PowerShell） |
| `scripts\run.bat measure-drop4` | ぽとん4 の CPU の強さを測る |
| `scripts\run.bat replay-othello` | オセロっちの動きが移植前と同じかを記録（`tests/golden/`）と照合する（数分かかる） |

ブラウザでテストを見るときは `tests/test.html` を開きます。

## フォルダの構成

| 場所 | 中身 |
|---|---|
| `index.html` | 入口ページ |
| `core/` | 全ゲーム共通の部品（保存・キャラ・セリフ選び・表情・演出・音・BGM・ヘッダー） |
| `css/` | 共通の見た目（色・土台・ヘッダー・演出） |
| `games/drop4/` | ぽとん4 |
| `games/othello/` | オセロっち（移植。中のつくりは移植元のまま） |
| `assets/characters/` | 表示用のキャラ画像（512x512 透過 PNG）。決まりは `assets/README.md` |
| `assets-src/` | 元画像（ゲームからは読まない） |
| `tests/` | 自動テスト・静的検査・計測ツール |
| `tools/` | 画像の縮小ツール・仮絵の生成ツール |
| `scripts/run.bat` | 開発用コマンドの入口 |
| `.claude/docs/` | 要件・設計・計画などの開発文書 |

旧「ぱたぱた！オセロっち」の文書（遊び方・GitHub Pages での公開手順・拡張ポイントなど）は `.claude/docs/legacy-othello/` にあります。

## iPhone で遊ぶときの注意

- iPhone の**マナーモード（消音）では音が鳴らないことがあります**。音を聞きたいときは、消音スイッチをオフにして、音量を上げてください。
- 音は最初に画面をタップしたときから鳴ります（ブラウザの決まりです）。
