# ピースじんとり CPU 強さ計測レポート（2026-11-20）

## 方法
- ツール: `scripts\run.bat measure-territory [--seed N] [--games N] [--strong-games N] [--think-games N] [--only weak+normal+strong+vs+think] [--set level.key:値]`
- 2人 11×11。子ども役の席と先手を局ごとに入れかえ。CPU と子ども役は局ごとに別の seed（mulberry32）。勝率は引き分けを半分で数える。
- 子ども役（`tests/tools/child-territory.js`）: 70% で「いちばん大きいピースを使う手」の中からランダム、30% で全部の手からランダム（設計書 §6.2）。
- 4人 14×14 の思考時間: 「ふつう」3人＋子ども役 1人を 20 局。`Ai.chooseMove` 1回の実時計。
- 試行は `--set` で一時的に値を差し替え、最終値だけを `constants.js` に書いた。

## CPU の考え方（`games/territory/js/ai.js`）
- 手の点 = size × 置くマス数 + mine × 自分の置ける角の数 − opp × 相手全員の置ける角の数 + 乱数 × noise。
- よわい: 点の差が小さい重み（size 1）で noise を大きくし、ほぼランダム。
- ふつう: size 3、noise 38。
- つよい: 点の上位 topK 手について、次に打つ席の最善手（同じ点）を引いた値で選ぶ（1手先読み）。`now` で 400ms 打ち切り。

## 調整の経過（子ども役の勝率、200 局）

| 対象 | パラメータ | 勝率 | 判断 |
|---|---|---|---|
| ふつう | noise 6（初期値） | 13.8%（40 局） | 強すぎ |
| ふつう | noise 15 / 25 / 40 | 34.8% / 43.8% / 53.0% | |
| ふつう | noise 30 / 35 / 45（seed 1〜3） | 43.8〜48.8% / 45.3〜49.8% / 53.5〜57.5% | |
| ふつう | **noise 38** | 51.8〜52.5%（seed 1・2） / 48.0%（seed 3） | 採用 |
| よわい | noise 100 | 78.3% | 上限ぎりぎり |
| よわい | noise 200〜400 | 85〜87% | 上限超え（ランダムに近づくほど子ども役が有利） |
| よわい | noise 60 / 70（seed 1〜4） | 67.5〜78.5% / 70.3〜78.0% | |
| よわい | **noise 75** | 79.5%（seed 1）、seed 2〜3 は 75% 前後 | 採用 |
| つよい | topK 12 → 30 | ふつうに 93.0% → 95.5%（100 局） | 時間に余裕があるので 30 |

## 最終パラメータ（`games/territory/js/constants.js`）
- weak: `{ size: 1, mine: 1, opp: 1, noise: 75 }`
- normal: `{ size: 3, mine: 1, opp: 1, noise: 38 }`
- strong: `{ size: 3, mine: 1, opp: 1, noise: 0, budgetMs: 400, topK: 30, reply: 0.5 }`

## 最終結果（`scripts\run.bat measure-territory --games 200 --strong-games 200 --think-games 20`、seed 1）

| 組 | 局数 | 結果 | 目標 |
|---|---|---|---|
| よわい vs 子ども役 | 200 | 子ども役 79.5% | 70〜80% ○ |
| ふつう vs 子ども役 | 200 | 子ども役 52.5% | 45〜55% ○ |
| つよい vs 子ども役 | 200 | 子ども役 7.8% | （目標なし） |
| つよい vs ふつう | 200 | つよい 94.5% | 80% 以上 ○ |

- 思考時間: ふつう（4人 14×14、535 手）最大 4.1 ms・平均 1.0 ms（目標 500 ms 以内 ○）。つよい（2人）最大 74.8 ms・平均 15.2 ms（400 ms 打ち切りには届かない）。

## 注意
- よわいは seed によって 70〜80% の間で揺れる（上表、seed 1〜4 で 67〜80%）。seed 1 は上限に近い。
- 子ども役の妥当性と「つよい」が「ママが勝ったり負けたり」になるかは実機テストで確かめる。3〜4人の強さは計測していない。
