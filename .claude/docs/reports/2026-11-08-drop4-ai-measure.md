# ぽとん4 CPU 強さ計測レポート（2026-11-08）

## 方法
- ツール: `scripts\run.bat measure-drop4 [--seed N] [--games N] [--strong-games N] [--only weak+normal+strong+vs] [--set level.key:値]`
- 2人・7×6・ぬきとり/ブロックなし。先手を1局ごとに交互。CPU と子ども役は局ごとに別の seed（mulberry32）。
- 子ども役（`tests/tools/child-proxy.js`）: すぐ勝てる手 80%、相手のすぐ勝つ手を止める 50%、それ以外は中央寄りのランダム（設計書 §6.3）。
- 思考時間は `Ai.chooseMove` 1回の実時計（performance.now）。
- 試行は `--set` で一時的に値を差し替えて実施し、最終値だけを `constants.js` に書いた。
- 「つよい」は1局約 1.8 秒。200 局×2 組は約 12 分で 10 分を超えるため、Ruling R11 に従い 100 局ずつ。

## 調整の経過（子ども役の勝率。200 局、seed 1。複数 seed は seed 1〜4）

| 対象 | パラメータ | 子ども役の勝率 | 判断 |
|---|---|---|---|
| よわい | winRate 0.6 / blockRate 0.3（初期値） | 60.5% | 弱さ不足 |
| よわい | blockRate 0.1 / 0 | 64.0% / 68.0% | blockRate だけでは届かない |

| よわい | 0.5 / 0.1 | 68.0〜75.5%（平均 71.9%） | 下限割れの seed あり |
| よわい | **0.4 / 0.1** | 71.5〜78.5%（平均 74.9%） | 採用 |

| ふつう | 追加パラメータ missRate を導入。depth 4 / noise 150 / missRate 0.5 | 30.0% | |
| ふつう | depth 4 / noise 300 / missRate 0.7 | 44.5% | |
| ふつう | depth 4 / noise 1000 / missRate 0.7 | 49.5% | |
| ふつう | **depth 4 / noise 500 / missRate 0.7** | 47.0〜53.5%（平均 49.3%） | 採用 |

### 追加パラメータ `normal.missRate` の理由
- 「すぐ勝つ手・止める手は必ず打つ」を守ると、それ以外を完全ランダムにしても子ども役の勝率は約 36% が上限（上表）。子ども役は相手のリーチを 50% しか止めないのに、CPU は 100% 止めるため。
- そこで「相手のリーチを見落とす確率」`missRate` を1つ追加した。見落としたときはリーチの列を候補から外す（外さないと深さ 4 の探索が結局止めてしまう）。自分のすぐ勝つ手は常に打つ。
- このため設計書 §6.2「ふつう：止める手は必ず打つ」とは異なる。テストは missRate を 0 にして止める仕組みを確認し、別のテストで出荷値の止める率（約 1 − missRate）を確認している。

## 最終パラメータ（`games/drop4/js/constants.js`）
- weak: `{ winRate: 0.4, blockRate: 0.1, blockUseRate: 0.02 }`
- normal: `{ depth: 4, noise: 500, missRate: 0.7 }`
- strong: `{ budgetMs: 400, maxDepth2p: 10, maxDepthMulti: 5 }`（初期値のまま）
