## 3. 変えたこと

| 項目 | 内容 |
|---|---|
| 音 | オセロっちのトップ・ゲーム中・ヘッダーの音ボタンは、すべて共通設定 `ailand:core:settings.v1` の sound を切り替える。`Ailand.core.Sound.onChange` で、どこで切り替えても全部の表示が追いつく（不具合 (b)）。オセロの効果音も共通設定に従う |
| せってい | ヘッダーの「せってい」で設定画面を開く（トップ：BGM の ON/OFF、ゲーム中：はじめから・トップに もどる・BGM）（不具合 (a)） |
| 保存・イベントバス | `core/storage.js`・`core/event-bus.js` を使う。保存キーは `ailand:othello:save.v1`・`settings.v1` のまま（移行処理なし） |
| キャラ・セリフ | キャラは `core/characters.js` だけ。セリフは `games/othello/js/data/lines.js`（旧ファイルと JSON で完全一致を確認）。キャラ追加は「画像＋core 1エントリ＋各ゲームのセリフ」で済む（オセロのセリフがなければ共通セリフ） |
| 演出まとめ | `games/othello/js/game/move-reaction.js` が `core/reaction.js` の batcher を使う。演出の選び方は今までの `O.Reaction.pickEffect` |
| 操作 | 盤は Pointer Events（core/pointer.js、指ごとに押したマスを覚える）＋キーボードの Enter。盤とボタンは `touch-action: none`。マス以外の押せる所は 64px 以上。本文は 18px。縦画面の操作ボタンは2段（3×2、4人は4＋3） |
