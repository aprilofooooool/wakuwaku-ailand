# ピースじんとり（territory）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 8本目のゲーム「ピースじんとり」（2〜4人の対戦。自分の色のピースを角だけでつなげて広げ、置いたマスが多い人の勝ち）を作り、入口から遊べるようにする。あわせてピースの形の計算とドラッグを `core/` へ移し、ピタうめっちもそれを使うようにする。

**Architecture:** 素の HTML/CSS/JS（IIFE、`window.Ailand`、file:// で動く）。`games/territory/` に、対戦・CPU・設定・つづきからはぽとん4（`games/drop4/`）、ドラッグと盤の描き方はピタうめっち（`games/fill/`）と同じ分け方で置く。pieces・engine・ai・reactions・controller・layout は DOM なしの純粋なコードで Node でテストする。盤は Canvas、札・置き場・ボタン・キャラは HTML。

**Tech Stack:** Vanilla JS（ES5 スタイル、`var`・IIFE）、Node の vm で動くテスト（`tests/run-node.js`、`describe`/`it`/`expect`）、ブラウザ用テスト `tests/test.html`。CPU の強さの計測は Node（`tests/tools/`）。

**Spec:** `.claude/docs/specs/2026-11-20-territory-design.md`（以下「設計」）。見本：`games/drop4/`（controller・ai・reactions・設定画面）、`games/fill/`（drag・render・置き場）、`.claude/docs/plans/done/B-8_pita/2026-11-17-plan.md`。backlog: B-9（`.claude/docs/plans/backlog.md` が正）。

## Global Constraints

- ES Modules・fetch・Worker・外部 CDN・外部フォント・`getImageData` 禁止。file:// で動くこと（`tests/static-check.js` が検査）。localStorage は `core/storage.js` 経由だけ。
- ファイル名・フォルダ名は `^[a-z0-9.-]+$`。新しいテストファイルはすべて `tests/test.html` に載せる（static-check が検査）。
- ゲーム id は `territory`、表示名は「ピースじんとり」。名前空間 `Ailand.games.territory`。効果音名は `territory-` で始める。
- 画面の文言はひらがな中心。コード・識別子・コメントは英語。セリフは1つ20文字以内、公式セリフは使わない。既存の作品の名前・見た目・ピースの色の並びに似せない（設計 §1.3）。
- 操作規約：盤・置き場・ボタンに `touch-action: none; user-select: none; -webkit-user-select: none; -webkit-touch-callout: none`（設定画面だけ `pan-y`）。ボタンは 64×64px 以上、本文 18px 以上。iPhone 縦 390×844px でスクロールなしに全部収まり、14×14 の盤で1マス 24px 以上（設計 §4.4）。
- 盤：2人 11×11、3人・4人 14×14。はじめのすみ：1P 左上、2P 右上（2人では右下）、3P 右下、4P 左下（設計 §2.1）。
- ピース：1人12個・合計44マス（設計 §2.2 の表）。盤の大きさとピースの形はユーザーが決めたので変えない（設計 §10）。
- 保存キーは `ailand:territory:settings.v1` と `ailand:territory:save.v1` だけ（`Storage.create('territory')`）。BGM の ON/OFF は core の `Sound` 側。
- 置いた本人に自分の手の直後のいやな顔を出さない。画面全体の演出は1手に1つ（要件 1.6）。`prefers-reduced-motion` のときは跳ねる・光る・紙吹雪・点の点滅を止める（設計 §5.1）。
- CPU：最低 600ms 待って置く。「ふつう」の1手は 4人 14×14 で最大 500ms 以内（Node 計測）。強さの目標は2人戦だけで合わせる（設計 §6.1、T5）。
- ピタうめっちの見た目・動き・保存を変えない。既存のテストは中身を変えずに通す（置き場所の移動と、`games.test.js` の ready 数・territory 行、`bgm-scores.test.js` の比較対象の追加だけ可）。
- コマンドは `scripts\run.bat test` / `check` / `serve`（`http://127.0.0.1:8080/`）/ `measure-territory`（Task 3 で足す）。
- コミットは `<type>: <日本語要約>`、末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。ブランチは `claude/territory-bd635b`。push しない。main へのマージはユーザーの了承を得てから。
- プロセスを止めるときは自分が起動した PID だけ（プロセス名指定の停止は禁止）。

## Review Focus

1. 盤のふち・相手のピースのすぐ横・自分のピースの角と辺の両方に触れる位置で離した → 決まりどおりの判定（辺が1つでも触れたら `edge` で置けない）、置けなければ置き場に戻り盤に何も残らない。→ Task 2 `edge wins over corner`・Task 7 `dropping on an illegal spot returns the piece`。
2. 人間の番がまわってきたが置ける手がない・CPU だけが残った・全員が同時に置けなくなった → 人間を待って止まらず、自動でおやすみにして進み、全員おやすみで必ず終わる。→ Task 2 `apply skips seats without a move and ends`・Task 5 `cpu-only rest plays to the end`。
3. 保存された履歴が壊れている・決まりに合わない手が混ざる・設定と人数が合わない → つづきからを出さず新しい局で開ける。→ Task 5 `broken save is discarded`。
4. CPU の考え中に「1手もどす」「もどる」「さいしょから」を押した → 考えていた手は捨てられ、古い手があとから置かれない。→ Task 5 `stale cpu move is dropped after undo or stop`。
5. ドラッグ中に2本目の指・pointercancel・番の交代（人間2人）が起きた → 2本目は無視、cancel では置き場に戻る、CPU の番には置き場をつかめない。→ Task 1 `core/drag` のテスト・Task 7 `tray is locked on a cpu turn`。

### Task 5: 進行と保存（controller）

**Files:**
- Create: `games/territory/js/controller.js`、`tests/territory/controller.test.js`

**Interfaces:**
- Consumes: `Engine`、`Ai`、`Reactions`、`Ailand.core.Storage`・`EventBus`・`EmotionVariety`。
- Produces（`Controller`。drop4 の `Controller.create(deps)` と同じ形）：`create({ bus, storage, ai, rng, now, setTimeout })`。メソッド：`loadSettings()`・`saveSettings(s)`・`hasSave()`・`start(settings)`・`resume() → boolean`・`input(move) → { ok, reason? }`・`stop()`・`canUndo()`・`undo()`・`undoLeft()`・`state()`・`settings()`・`isBusy()`・`seenHowTo()`・`markHowToSeen()`。イベント：`started`・`turn`・`moved`（`{ move, state }`）・`reaction`・`thinking`・`undo`・`gameover`（`{ result }`）。
- settings の形：`{ players: 2|3|4, seats: [{ seat, charId, human }], level, first: 'me'|'them'|'random', firstSeat }`（drop4 の形から teams・popOut・blocks を除く）。既定：2人・1P ひと／2P CPU・`weak`・`random`。
- `save.v1`：`{ settings, history: [move…], undoLeft }`。手ごとに保存、`gameover` で消す。`resume` は履歴を `Engine.apply` で再生し、1手でも `check` が通らなければ保存を消して false。
