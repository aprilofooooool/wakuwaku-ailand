# オセロっち core 乗せ替え・操作共通化・音設定一本化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** オセロっちを core の部品（キャラ・セリフ選び・保存・イベントバス・演出まとめ・Pointer）に乗せ替え、音のオンオフを共通設定1つにし、既知の不具合2件を直す。

**Architecture:** 素の HTML/CSS/JS（IIFE、`window.Ailand`、file:// で動く）。オセロ固有の判定（感情・演出の選び方・対局）は残し、汎用部品だけ core に寄せる。音は `Ailand.core.Sound` を唯一の正にし、変更通知 `Sound.onChange` で全表示を追従させる。

**Tech Stack:** Vanilla JS（ES5 スタイル、`var`・IIFE）、Node の vm で動くテスト（`tests/run-node.js`）、ブラウザ用テスト `tests/test.html`。

**Spec:** `.claude/docs/specs/2026-11-09-othello-core-migration-design.md`（以下「設計」）。backlog: D-1・U-1（`.claude/docs/plans/backlog.md` が正）。

## Global Constraints

- ES Modules・fetch・Worker・外部 CDN 禁止。file:// で動くこと（`tests/static-check.js` が検査）。
- 対局ロジック（engine・AI・reaction-engine・game-controller の進行）を変えない。`scripts\run.bat replay-othello` が golden `tests/golden/othello-replay.json` と一致し続けること。golden は再生成しない（`--write` 禁止。必要ならユーザーに確認）。
- 読み込み構成が変わったら `tests/tools/replay-othello.js` の FILES/NS と `tests/test.html` の script 一覧だけを直す。
- 保存キーは `ailand:othello:save.v1` / `ailand:othello:settings.v1` のまま。
- セリフ文字列は1文字も変えない。
- 操作規約（要件 1.2）: 盤とボタンに `touch-action: none`、盤のマス以外のタップ領域 64×64px 以上、本文 18px 以上、基準幅 iPhone 縦 390〜430px。
- コマンドは `scripts\run.bat test` / `scripts\run.bat check` / `scripts\run.bat replay-othello`（約4分、background で実行）。
- コミットは `<type>: <日本語要約>`、末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。ブランチ `feat/othello-core-migration`。push しない。
- プロセスを止めるときは自分が起動した PID だけ（プロセス名指定の停止は禁止）。

## Review Focus

1. 「moved」と感情イベントが別タスクで届いたとき、mover が次の flush まで持ち越される（今の batch と同じ）。→ Task 6 のテスト `mover is carried to a later flush`。
2. 共通の音 OFF のときにオセロの効果音が鳴らない（今は鳴る）。→ Task 2 のテスト `play is silent while core sound is off`。
3. ゲーム中の「おと」を押した直後、ヘッダーの音アイコンとトップの「おと：ON/OFF」が同じ値になる。→ Task 1 の DOM テスト `header repaints on Sound.onChange` ＋ Task 2 の手動確認。
4. 旧データに `ailand:othello:settings.v1` の `sound:false` が残っていても起動・保存が壊れない（読まない・書かない）。→ Task 2 のテスト `old settings with sound:false still load`（DOM なしで loadState を通せないため、`O.UI` の公開関数 `_normalizeSettings` を足してテストする）。
5. 指で盤のマスを押してから少しずらして離しても1回だけ置ける／マウス・指で二重に置かない。→ Task 7 の DOM テスト `cell tap places once`（browser-only）。
