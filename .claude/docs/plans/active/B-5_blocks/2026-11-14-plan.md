# おちブロック（blocks）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 4本目のゲーム「おちブロック」（1人用。ブロックにキャラの顔が付き、そろえて消すと顔が飛んでいく。選んだキャラの顔を目標の数集めたらクリア）を作り、入口から遊べるようにする。

**Architecture:** 素の HTML/CSS/JS（IIFE、`window.Ailand`、file:// で動く）。`games/blocks/` にキャラたたきと同じ分け方で置く。ルール（pieces・engine）と進行（controller）は DOM なしの純粋なコードにして Node でテストする。盤は Canvas に描き、飛ぶ顔・まわりの表示は HTML＋CSS（設計 §7）。core は `games.js` の1行だけ変える。

**Tech Stack:** Vanilla JS（ES5 スタイル、`var`・IIFE）、Node の vm で動くテスト（`tests/run-node.js`、`describe`/`it`/`expect`）、ブラウザ用テスト `tests/test.html`。

**Spec:** `.claude/docs/specs/2026-11-14-blocks-design.md`（以下「設計」）。backlog: B-5（`.claude/docs/plans/backlog.md` が正）。

## Global Constraints

- ES Modules・fetch・Worker・外部 CDN・外部フォント・`getImageData` 禁止。file:// で動くこと（`tests/static-check.js` が検査）。localStorage は `core/storage.js` 経由だけ。
- ファイル名・フォルダ名は `^[a-z0-9.-]+$`。新しいテストファイルはすべて `tests/test.html` に載せる（static-check が検査）。
- 画面の文言はひらがな中心。コード・識別子・コメントは英語。セリフは1つ20文字以内、公式セリフは使わない。既存ゲームの名前・見た目・音楽に似せない（設計 §1.3）。
- 操作規約：盤とボタンに `touch-action: none; user-select: none; -webkit-user-select: none; -webkit-touch-callout: none`。ボタンは 64×64px 以上、本文 18px 以上。iPhone 縦 390×844px でスクロールなしに全部収まる。
- 保存キーは `ailand:blocks:settings.v1` だけ（`Storage.create('blocks')` の `settings.v1`）。途中の状態・集めた顔・記録は保存しない（設計 §9・§12）。
- 選んだキャラに、自分の操作の直後で `worried`・`sadness`・`anger`・`panic` を出さない。`worried` は「おしまい」の結果画面だけ（設計 §2.5・§5.1）。
- `prefers-reduced-motion` のとき：顔は飛ばずにその場でふわっと消え、数はすぐ増える。紙吹雪・光る・揺れるは止める（設計 §5.2）。
- 既存ゲームの挙動とテストを変えない（`tests/core/games.test.js` の ready 数と `tests/core/bgm-scores.test.js` の比較対象を増やす以外）。
- コマンドは `scripts\run.bat test` / `scripts\run.bat check` / `scripts\run.bat serve`（ブラウザ確認、`http://127.0.0.1:8080/`）。
- コミットは `<type>: <日本語要約>`、末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。ブランチは `feat/blocks`。push しない。
- プロセスを止めるときは自分が起動した PID だけ（プロセス名指定の停止は禁止）。

## Review Focus

1. ボタンを押しっぱなしのまま一時停止（タブ非表示・もどる・せってい）して戻ると、ブロックが勝手に動き続けない。→ Task 5 のテスト `pause releases held buttons`。
2. 指がボタンからすべって外れた・pointercancel が来たとき、繰り返しが止まる。→ Task 7 の browser-only テスト `repeat stops on pointercancel and leave`。
3. 離れた2列（間に埋まっていない列がある）を同時に消したとき、上のマスが正しく下がり、顔とキャラがついていく。→ Task 3 のテスト `non-adjacent rows clear and cells keep their faces`。
4. 目標に届いた列消しと、出現枠がふさがる状況が同時に起きたとき、結果は「クリア」になる。列を詰める待ち時間の間の操作は何もしない。→ Task 3 のテスト `goal wins over a blocked spawn` と `inputs during settle do nothing`。
5. 保存された設定が壊れている（知らないキャラ、知らない難しさ、seenHowTo が真偽値でない、JSON でない値）とき、項目ごとに既定値で開く。→ Task 5 のテスト `broken settings fall back per field`。

### Task 2: 出る順・動く・落ちる・固定（engine 前半）

**Files:**
- Create: `games/blocks/js/engine.js`
- Modify: `tests/test.html`
- Test: `tests/blocks/engine.test.js`

**Interfaces:**
- Consumes: Task 1 の `Constants`・`Pieces`、`Ailand.core.Rng.mulberry32(seed) → () => number`。
- Produces（`Ailand.games.blocks.Engine`）：
  - `createBag(rng, items) → { next() → item }`：items を混ぜた1組を使い切ったら、次の組を混ぜる（設計 §2.2）。
  - `create({ difficulty, selfId, seed }) → Game`。`Game = { board, piece, next: { shape, charId }, selfId, goal, collected: 0, jar: 0, lines: 0, fallMs, state: 'falling'|'settling'|'goal'|'over', ... }`。形の袋とキャラの袋は同じ乱数列から作る（`mulberry32(seed)` を1つ）。キャラは `['mametchi', 'kuchipatchi', 'mimitchi', 'flowertchi']`。作った時点で最初の piece を出す（`x = 3, y = 0, rot = 0`）。
  - `move(game, dx) → boolean`、`rotate(game) → boolean`（`Pieces.tryRotate`）、`softDrop(game) → boolean`（1マス下げる）。`state` が `'falling'` 以外なら何もせず false。下に着いている状態で move/rotate が成功したら、固定までの待ちを 0 に戻す（1つの piece で `LOCK_RESETS` 回まで）。
  - `hardDrop(game) → Event[]`：影の位置まで下げてすぐ固定し、固定で起きた Event を返す。`'falling'` 以外は `[]`。
  - `step(game, ms) → Event[]`：`'falling'` のとき、落ちる時間を足し `fallMs` ごとに1マス下げる。下に着いていれば固定までの待ちを足し、`LOCK_MS` で固定する。
  - `ghostY(game) → number`：いまの piece をまっすぐ下げて止まる y。
  - Event（このタスクで出すもの）：`{ type: 'lock', cells: [col, row][] }`、`{ type: 'spawn', shape, charId }`。固定して消える列がなければ、すぐ次の piece を出す。出す場所がふさがっていたら `{ type: 'over' }` で `state = 'over'`。固定したマスの row がすべて `< HIDDEN` なら、次を出さずに `'over'`（設計 §2.5）。
- [ ] **Step 1: 失敗するテストを書く**（`board` を手で埋めて状況を作ってよい）
  - `bags give every shape once per 7 and every character once per 4`：同じ種で 28 個取り出し、7個ごとに全形1回ずつ、4個ごとに全キャラ1回ずつ。
  - `same seed gives the same sequence`：種 7 の Game 2つで 20 個の (shape, charId) が同じ。種 8 とは違う。
  - `move stops at walls and blocks`：左に 10 回 move → 途中から false、piece が盤の外に出ない。
  - `gravity drops one row per fallMs`：normal で step(649) は y 変化なし、step(1) で +1。
  - `lock after 500ms on the floor and reset on move up to 15 times`：床に着けて step(499) で lock なし、step(1) で lock。別の Game で、着いた後 move を 15 回はさむと毎回数え直し、16 回目以降は数え直さない。
  - `hardDrop locks at ghostY at once`：hardDrop の前の ghostY と lock の cells の最下段が一致、続けて spawn。
  - `spawn blocked ends the game`：row 0〜1 の x=3〜6 を埋めてから固定 → `over`、以降 move は false、step は `[]`。
  - `locking entirely in the hidden rows ends the game`。

### Task 5: 進行（controller）

**Files:**
- Create: `games/blocks/js/controller.js`
- Modify: `tests/test.html`
- Test: `tests/blocks/controller.test.js`

**Interfaces:**
- Consumes: `Engine`（Task 2・3）、`Ailand.core.EventBus.create() → { on, emit }`、storage（`get(key, fallback)`/`set(key, v)` を持つもの。テストは偽物）。
- Produces（`Ailand.games.blocks.Controller.create({ bus, storage, seed })`。`seed()` は新しい種の整数を返す）：
  - `loadSettings() → { char, difficulty, seenHowTo }`。既定 `{ char: 'mametchi', difficulty: 'easy', seenHowTo: false }`。項目ごとに検査し、だめな項目だけ既定値。保存値がオブジェクトでなければ全部既定値。
  - `needsHowTo() → boolean`、`markHowToSeen()`（`seenHowTo: true` を保存）。
  - `start(settings)`：設定を `settings.v1` に保存。`Engine.create({ difficulty, selfId: settings.char, seed: seed() })`。phase `'countdown'`。
  - `advance(ms)`：一時停止中、phase が `'countdown'`/`'playing'` 以外は何もしない。countdown：3000→0 の間に `emit('count', { n })`（3・2・1 を各1秒の頭で1回ずつ）、0 で `emit('go', {})`、`emit('spawn', …)`（最初の piece）して `'playing'`。playing：押しっぱなしの繰り返しを処理し、`Engine.step` の Event をそれぞれ `emit(e.type, e)`。`dangerous` が変わったら `emit('danger', { on })`。goal か over が来たら phase `'result'`、`emit('result', getResult())`。
  - `press(action: 'left'|'right'|'rotate'|'soft'|'hard') → boolean`：playing かつ一時停止でないときだけ。left/right は1回動かし、押しっぱなしとして記録（`REPEAT_DELAY_MS` 後から `REPEAT_MS` ごとに繰り返す）。soft は1回下げ、押している間 `SOFT_MS` ごと。rotate は1回。hard は `Engine.hardDrop` の Event を emit。動いたら `emit('moved', { action })`（音のため）。
  - `release(action)`：その action の押しっぱなしをやめる。
  - `pause(reason: 'hidden'|'menu'|'back')`：押しっぱなしをすべてやめる。`resume()`・`isPaused()`・`phase()`・`game()`（描画用に Game を返す）。
  - `getResult() → { cleared: boolean, collected, goal, jar, char }`。
  - `quit()`：phase `'idle'`。

  - `holding left repeats after 170ms every 50ms`：press('left') で x−1、advance で 169ms までは変わらず、170ms で −1、以後 50ms ごと。release で止まる。
  - `soft drop repeats every 50ms while held`。
  - `pause releases held buttons`：press('left') → pause('hidden') → resume → 1000ms 進めても左に動かない。一時停止中の advance で時間が進まない（落ちない）。一時停止中の press は false。
  - `goal and over end with a result`：Engine の Game を手で整えて goal → result の `cleared: true`。over → `cleared: false`。
  - `danger is emitted only on change`。
  - `broken settings fall back per field`：Review Focus 5 の4種類。
  - `how-to is shown once`：初回 needsHowTo true、markHowToSeen 後 false（保存される）。
