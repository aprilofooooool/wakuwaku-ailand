# ぷにっち（chain）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 6本目のゲーム「ぷにっち」（1人用。2個1組の玉を同じ色4つ以上つなげて消し、となりで眠っている友だちを起こす。全員起こしたらクリア）を作り、入口から遊べるようにする。

**Architecture:** 素の HTML/CSS/JS（IIFE、`window.Ailand`、file:// で動く）。`games/chain/` にテトリっち（`games/blocks/`）と同じ分け方で置く。ルール（pair・engine）・反応（reactions）・進行（controller）は DOM なしの純粋なコードにして Node でテストする。盤は Canvas、飛ぶ友だち・まわりの表示は HTML＋CSS。時計・押しっぱなし・一時停止・結果・タイム記録はテトリっちのコードを写して直す（設計 §13 の案 1。`games/blocks/` は変えない）。

**Tech Stack:** Vanilla JS（ES5 スタイル、`var`・IIFE）、Node の vm で動くテスト（`tests/run-node.js`、`describe`/`it`/`expect`）、ブラウザ用テスト `tests/test.html`。

**Spec:** `.claude/docs/specs/2026-11-15-puni-design.md`（以下「設計」）。見本：`games/blocks/` と `.claude/docs/specs/2026-11-14-blocks-*.md`。backlog: B-7（`.claude/docs/plans/backlog.md` が正）。

## Global Constraints

- ES Modules・fetch・Worker・外部 CDN・外部フォント・`getImageData` 禁止。file:// で動くこと（`tests/static-check.js` が検査）。localStorage は `core/storage.js` 経由だけ。
- ファイル名・フォルダ名は `^[a-z0-9.-]+$`。新しいテストファイルはすべて `tests/test.html` に載せる（static-check が検査）。
- ゲーム id は `chain`、表示名は「ぷにっち」。名前空間 `Ailand.games.chain`。効果音名は `chain-` で始める。
- 画面の文言はひらがな中心。コード・識別子・コメントは英語。セリフは1つ20文字以内、公式セリフは使わない。既存ゲームの名前・見た目・音楽・用語（連鎖の掛け声など）に似せない（設計 §1.3・§5.4）。
- 操作規約：盤とボタンに `touch-action: none; user-select: none; -webkit-user-select: none; -webkit-touch-callout: none`。ボタンは 64×64px 以上、本文 18px 以上。iPhone 縦 390×844px でスクロールなしに全部収まる。
- 保存キーは `ailand:chain:settings.v1` と `ailand:chain:time.v1` だけ（`Storage.create('chain')`）。途中の状態は保存しない（設計 §9・§12）。
- 選んだキャラに、自分の操作の直後で `worried`・`sadness`・`anger`・`panic` を出さない。寝返りは `surprised` まで。`worried` は負けの結果画面だけ（設計 §2.5・§5.1）。
- 1回の固定（連鎖の全段を含む）につき画面全体の演出は1つ、吹き出しも1つ（設計 §5.1・§5.3）。
- `prefers-reduced-motion` のとき：ぷるぷる・飛ぶ動き・紙吹雪・光る・揺れるを止め、その場でふわっと消えて数がすぐ変わる（設計 §5.2）。
- `games/blocks/` のファイルと既存のテストを変えない（`tests/core/games.test.js` の ready 数・chain 行と `tests/core/bgm-scores.test.js` の比較対象を増やす以外）。
- コマンドは `scripts\run.bat test` / `scripts\run.bat check` / `scripts\run.bat serve`（ブラウザ確認、`http://127.0.0.1:8080/`）。
- コミットは `<type>: <日本語要約>`、末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。ブランチは `feat/chain`。push しない。
- プロセスを止めるときは自分が起動した PID だけ（プロセス名指定の停止は禁止）。

## Review Focus

1. 回して子の玉が見えない出現枠（row 0）に入ったまま固定した → その玉は残るが描かれず、つながりに数えず、寝返りの対象にもならない。ゲームは続く。→ Task 2 `a ball locked in the hidden row stays but never pops`。
2. 壁ぎわ（col 0・col 5）や積んだ玉のすぐ横で回す、子が床の下に回る → 反対側1・上1 にずれて回る。どれもだめなら回らない。→ Task 1 `kicks: opposite side then up`。
3. 連鎖の途中で残り時間が0になり、後の段で最後の友だちを起こした → クリア。起こした延長で時間が0より大きく戻った → 続く。→ Task 3 `timeout during a chain waits for the chain`。
4. 寝返りの予告中に、その友だちが起きた・となりの玉が消えた・連鎖で位置が変わった → その回は何もしない。消し・連鎖の途中では寝返りの時間が進まない。→ Task 4 `a warned turn is cancelled when the board changed`。
5. ボタンを押しっぱなしのまま一時停止して戻ると、組が勝手に動き続けない。保存値が壊れていても項目ごとに既定値で開く。→ Task 6 `pause releases held buttons`・`broken settings and times fall back`。

### Task 3: 消える・起きる・連鎖・時間・クリア（engine 中盤）

**Files:**
- Modify: `games/chain/js/engine.js`
- Test: `tests/chain/engine.test.js`

**Interfaces:**
- Produces（Task 2 に足す）：

  - settling の進み方（設計 §2.4）：ちぎれ待ちの終わりに `groups`。あれば `chain += 1` して `{ type: 'pop', chain, cells: [{ col, row, charId }] }` を出し `WOBBLE_MS` 待つ。待ち終わりに玉を消し、消えた玉と上下左右でとなり合うねむりマスをすべて空きにして、1人以上なら `{ type: 'wake', cells: [{ col, row, charId }], left }` と `{ type: 'time', addMs: 人数 × wakeMs }` を出し `woke`・`timeMs` に足す。続けて重力（玉もねむりマスも落ちる）で `fall` を出して待ち、また `groups` へ。なければ settle を終える。`chain` は固定ごとに 0 から。
  - settle の終わり（設計 §2.5）：ねむりマスが0 → `{ type: 'clear' }`、`state = 'clear'`。そうでなく `timeMs <= 0` → `{ type: 'over', reason: 'timeup' }`。そうでなければ `{ type: 'settled', chain: その固定の最大の chain, woke: その固定で起きた人数 }` を出してから次の組（ふさがっていれば blocked）。
  - 時間：`step` は falling と settling の間 `elapsedMs` を足し `timeMs` を減らす（0 で止める）。falling で 0 になったら timeup。settling では判定しない。
  - `almost`：ねむりマスが初めて1人になったとき `{ type: 'almost' }` を1回だけ（`wake` の直後）。一気に0人になったら出さずに使い切る（設計 §3.3）。
  - 盤のねむりマスの数を `game.sleepers` に保つ。
