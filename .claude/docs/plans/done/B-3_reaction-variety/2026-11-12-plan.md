# キャラの反応バリエーション追加（B-3）実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3ゲームで、同じ場面でも表情を2〜3種類から選んで出す。あわせて、待ちくたびれ（sleep）、キャラたたきの「れんぞく」、オセロっちの表情の印を足す。

**Architecture:** 「候補から選び、同じ表情を3回続けない」処理と、「20秒操作がないと知らせるタイマー」を core に1つずつ置き、各ゲームから使う。ぽとん4は controller で表情を選び直す。オセロっちは画面側（`ui/`）だけで表示する顔を選び直す（controller と golden にはさわらない）。キャラたたきは `js/reactions.js` を広げる。

**Tech Stack:** Vanilla JS（IIFE、`Ailand` 名前空間）。テストは自前ランナー（`tests/test.html` に並べたファイルを `scripts\run.bat test` が node で実行）。

**Spec:** `.claude/docs/specs/2026-11-12-reaction-variety-design.md`（実装者は計画とあわせて必ず読む）

## Global Constraints

- コミットは `<type>: <日本語要約>` の形。最後に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` を付ける。
- セリフは20文字以内（`Array.from` で数える）、ひらがな多め、公式のセリフは使わない。口調は同じファイルの今のセリフに合わせる。
- 手を打った本人には、自分の手の直後にいやな顔（anger・sadness・panic・worried・surprised）を出さない。
- 画面全体の演出と音は増やさない。
- オセロっちの `games/othello/js/game/`・`engine/` は1行も変えない。`tests/golden/othello-replay.json` は作り直さない。
- 保存キーは変えない。旧オセロっちの `otc.*` にはふれない。
- 新しい core ファイルは、`tests/test.html` と、使うゲームの `index.html` の両方に `<script>` を足す（`tests/run-node.js` は `tests/test.html` の並びを読む）。
- テストは `scripts\run.bat test`、静的チェックは `scripts\run.bat check`。`scripts\run.bat replay-othello` は約3.5分かかるので background で実行する。
- プロセスを止めるときは、自分が起動した PID だけを止める。名前を指定して止めない。

### Task 2: core の IdleTimer と sleep の印

**Files:**
- Create: `core/idle-timer.js`
- Modify: `core/emotion-map.js`（`'sleep': { image: 'sleep', mark: 'zzz' }`）
- Test: `tests/core/idle-timer.test.js`、`tests/core/emotion-map.test.js`（sleep の mark が `'zzz'`）
- Modify: `tests/test.html`

**Interfaces:**
- Produces: `Ailand.core.IdleTimer.create({ ms: number, onIdle: () => void, onWake: () => void, timers?: { setTimeout, clearTimeout } }) -> { arm(), poke(), pause(), resume(), stop(), state(): 'off'|'counting'|'paused'|'asleep'|'done' }`
  - `arm()`：数え始める（`counting`）。前の状態は捨てる。
  - `poke()`：`counting` なら0から数え直す。`asleep` なら `onWake()` を呼んで `done`（その番ではもうねむらない）。ほかは何もしない。
  - `pause()`：`counting` なら止めて `paused`。`resume()`：`paused` なら0から数え直して `counting`。
  - `stop()`：タイマーを止める。`asleep` なら `onWake()` を呼ぶ。`off` になる。
  - `ms` 経過で `onIdle()` を呼んで `asleep`。

- [ ] **Step 1: 失敗するテストを書く**（偽の timers を渡し、手で時間を進める）
  - `fires once after ms`：`arm()` → 19999ms で `onIdle` 0回、20000ms で1回、さらに 40000ms 進めても1回。
  - `poke restarts counting`：`arm()` → 15000ms → `poke()` → 15000ms で0回 → 5000ms で1回。
  - `wake once per turn`：ねむったあと `poke()` で `onWake` 1回・`state()==='done'`。さらに 30000ms 進めても `onIdle` は増えない。
  - `pause and resume restart from zero`：`arm()` → 15000ms → `pause()` → 30000ms で0回 → `resume()` → 19999ms で0回 → 1ms で1回。
  - `stop wakes and turns off`：ねむったあと `stop()` で `onWake` 1回・`state()==='off'`。
  - emotion-map：`resolve('sleep')` が `{ image: 'sleep', mark: 'zzz' }`。
- [ ] **Step 2: テストが失敗することを確かめる**
- [ ] **Step 3: 実装する**（`timers` の既定は `window.setTimeout`・`window.clearTimeout`）。`core/emotion-map.js` の sleep 行の mark を `'zzz'` にする。
- [ ] **Step 4: `scripts\run.bat test` がすべて通ることを確かめる**
- [ ] **Step 5: コミット** `feat: 操作がないことを知らせるタイマーと sleep の印を足す`
