ぽとん4：コマの落とし方・ぬきとり・おじゃまブロックの操作案（タップして試せます）

案A：下のボタンで「おとす／ぬく／ブロック」を切り替える

・ふだんは「おとす」。列をタップ → 上にうすいコマ（ゴースト）が出る → 同じ列をもう一度タップで落ちる。

・「ぬく」を押すと、抜ける自分のコマが光る → 光ったコマをタップ → もう一度タップで抜ける。

・「ブロック」を押すと、落とすものが灰色ブロックに変わる（のこり数を表示）。

案B：切り替えなし。ボタンは「ブロック」だけ

・列の上半分〜空きマスをタップ → ゴースト → もう一度で落ちる。

・いちばん下の自分のコマを直接タップ → 「ぬく？」のゴースト表示 → もう一度で抜ける。

・切り替えが少ない分、まちがえて抜こうとして落とす（またはその逆）が起きやすい。
