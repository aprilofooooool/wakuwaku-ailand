# BGM の曲調の作り分け 設計書

- 作成日：2026-11-12
- 状態：ユーザー承認済み（2026-11-12）
- 位置づけ：トップページと3ゲーム（ぽとん4・オセロっち・キャラたたき）の BGM の正。`2026-11-08-ailand-phase1-design.md` の「BGM 通常 120bpm／終盤 150bpm」の行（§ 音の表）は本書で置き換える。
- 表記：「（判断）」は本書作成者が決めた点。ユーザーが合意した点には付けない。
- 楽譜の正：`.claude/docs/specs/bgm-drafts/bgm-trial.html`（ユーザーが聞いて「この方向で進めて」と承認した試作。2026-11-12）。音の高さ・長さ・音色・テンポは、この試作の `SONGS` の4曲をそのまま本番に移す。

## 1. 目的

- ユーザーの指摘：4曲が似ていて面白みがない。
- 原因（調査結果）：4曲とも長調・三角波のメロディ・低音は「1拍目と3拍目に根音→5度」・テンポ 120〜132 で、作りの型がほぼ同じ。ぽとん4とキャラたたきはコード進行（C→Am→F→G）と音階まで同じ。
- 守る体験：**ゲームを選んだとき**（ゲームの画面が開いて BGM が鳴り始めたとき）、出だしの数秒で「あ、〇〇の曲だ」と分かる。

### 1.1 ゴール
- 4曲が、聞いてすぐ違いがわかる。違いは調・コード進行・リズムの型・音色・メロディの性格・テンポの全部で出す。
- どの曲も楽しいポップな BGM のまま。
- 各曲の個性は出だし1〜2小節にいちばん強く出す。

### 1.2 やらないこと（非ゴール）
- 効果音の変更。
- BGM の鳴らし方（いつ始まり・止まり・テンポが上がるか、ON/OFF、音量の設定）の変更。
- 音声ファイルの追加。外部ライブラリの追加。

### 1.3 アンチゴール（動いても失敗とみなすもの）
- 公式の曲や実在の曲のメロディに似ている。
- どれかの曲が暗い・こわい・眠い（「楽しいポップ」でなくなる）。
- 打楽器や新しい音色が、効果音やキャラのセリフをかき消すほどうるさい。耳が痛い高い音。
- 4曲のどれか2曲を、出だしで取り違える。

## 2. 4曲の性格

| | トップ | ぽとん4 | オセロっち | キャラたたき |
|---|---|---|---|---|
| 曲名（判断） | ようこそファンファーレ | ぽよんぽよんシャッフル | ひなたぼっこワルツ | ドタバタ・ダッシュ |
| 性格 | 明るい入口・行進曲 | はずむ | ほのぼの | せわしなく元気 |
| 調 | ニ長調 | 変ロ長調 | 変ホ長調 | ホ長調 |
| コード進行 | D G A D / Bm G A D | B♭ Gm Cm F / B♭ Gm E♭-F B♭ | E♭ E♭ A♭ B♭ / Cm A♭ B♭ E♭ / A♭ B♭ Gm Cm / A♭ B♭ E♭ E♭ | A B G♯m C♯m / A B C♯m B（4→5→3→6 の進行） |
| 拍子・長さ | 4拍子・8小節（32拍） | 4拍子・8小節（32拍） | **3拍子**・16小節（48拍） | 4拍子・8小節（32拍） |
| リズムの型 | まっすぐな8分音符の行進 | **スイング**（裏の8分音符を3連符の位置まで遅らせる） | ズン・チャッ・チャッのワルツ | 16分音符の細かい動き＋4つ打ち |
| テンポ | 112 | 100（終盤 126） | 144（1小節 約1.25秒） | 150（残り10秒 180） |
| メロディの音色 | 矩形波（ラッパ風） | 正弦波が下から「ぽよん」とすくい上がる | 正弦波＋1オクターブ上のきらっとした音（オルゴール風） | のこぎり波・短く切る（ピコピコ） |
| 低音 | 正弦波・1拍目と3拍目 | 三角波・オクターブではねる | 正弦波・1拍目だけ | 三角波・8分音符でオクターブを往復 |
| 和音 | 三角波・2拍目と4拍目（2音） | 正弦波・裏拍（2音） | 三角波・2拍目と3拍目（2音） | 矩形波・短い「チャッ」（2音） |
| 打楽器 | キック1・3拍、スネア2・4拍、最終小節にスネアの連打 | キック1・3拍、ハイハット裏拍（スイング） | なし | キック毎拍、スネア2・4拍、ハイハット裏拍 |
| 出だしの目印 | 「タタタ・ターン」と駆け上がるファンファーレ | 跳ねながら大きく跳ぶ音 | ゆったりした3拍子のオルゴール | 細かく駆け回るピコピコ |

- 4曲とも長調のポップ。メロディはすべてこの作業のために作ったオリジナル。
- 終盤のテンポ（判断）：ぽとん4は今の「120→150」と同じくらいの上がり方（約1.25倍）で 100→126。キャラたたきは 132→168 と同じくらい（約1.2倍）で 150→180。

## 3. 制約

- Vanilla JS・IIFE・`Ailand` 名前空間。GitHub Pages でも file:// でも動く。
- 音は Web Audio で合成する。打楽器の「シャッ」は、コードの中で作る雑音（ホワイトノイズの AudioBuffer）を使う（判断）。音声ファイルは置かない。
- 今の楽譜のルールを守る：鳴る音は 100〜1600 Hz、メロディの9割以上は 400〜1200 Hz。打楽器の音（キックの音程の下がり方・雑音の帯域）はこのルールの対象外にする（判断）。
- オセロっちの対局ロジック（`games/othello/js/game/`・`engine/`）は変えない。`tests/golden/othello-replay.json` は作り直さない。
- 保存キー・旧オセロっちの保存データ（`otc.*`）にはさわらない。

## 4. 共通のしくみ（`core/bgm.js`）に足すもの

楽譜（score）に次の項目を足す。**どれも省略できて、省略したときは今と同じ鳴り方**にする（今の楽譜やテストがそのまま動くため）。

| 項目 | 意味 | 省略時 | 試作の値 |
|---|---|---|---|
| `gate` | メロディの音を、楽譜の長さの何割だけ鳴らすか | 0.92 | トップ 0.85、ぽとん4 0.7、オセロっち 0.8、キャラたたき 0.6 |
| `melodyPeak` | メロディの音量（音色ごとの聞こえ方の差をそろえる） | 0.32 | トップ 0.36、ぽとん4 0.336、オセロっち 0.32、キャラたたき 0.176 |
| `bassWave` | 低音の音色 | 'sine' | §2 |
| `chordWave` | 和音の音色 | 'sine' | §2 |
| `chordLen` | 和音の1音の長さの上限（秒） | 0.12 | トップ 0.18、ぽとん4 0.1、オセロっち 0.14、キャラたたき 0.08 |
| `bend` | メロディの音を、この割合の低い音から始めて本来の高さへすくい上げる（0.06 秒か音の長さの半分の短い方で到達） | なし | ぽとん4 0.82 |
| `sparkle` | メロディに1オクターブ上の正弦波を小さく重ねる（音量 0.06、長さは音の長さか 0.5 秒の短い方） | なし | オセロっち true |
| `swing` | 拍の裏（拍の頭から 0.5 拍の位置）の音を、この拍数だけ遅らせる。メロディ・低音・和音・打楽器の全部に効く | 0 | ぽとん4 1/6（3連符の位置） |
| `drums` | 打楽器の列 `[[種類 または 0, 拍数], ...]`。種類は `'k'`（キック）、`'s'`（スネア）、`'h'`（ハイハット）、`'ks'`（キックとスネアを同時） | なし | §2 |

- 和音の1つの音の高さは、数のほかに**数の配列**も書ける（例 `[[369.99, 440], 1]`）。配列のときは全部を同時に鳴らす。
- 打楽器の音の作り（試作の値）：
  - キック：正弦波 150 Hz → 50 Hz に 0.12 秒で下げる。音量 0.55、長さ 0.14 秒。
  - スネア：雑音をバンドパス（1800 Hz）に通す。音量 0.32、長さ 0.12 秒。
  - ハイハット：雑音をハイパス（7000 Hz）に通す。音量 0.18、長さ 0.04 秒。
  - 雑音のバッファは AudioContext ごとに1回だけ作る（0.5 秒分）。
- 音量の比率は試作と同じにする。試作は全体の音量が本番のちょうど2倍だった（本番の BGM バスは master 0.25 × BGM 0.5）。各声部の音量の値はそのまま移す。今の値とのちがい：低音 0.38→0.34、和音 0.12→1音あたり 0.08（判断：試作で聞いたバランスに合わせる）。
- `notesBetween` は、打楽器の音も返す（`drum: 種類` を付ける）。スイングで遅らせた位置は、拍の数え方（`beat`）は変えずに、別の項目で返す（判断：今の「テンポが変わっても拍が続く」しくみとテストを崩さないため）。
- `stop()` とタブが隠れたときの扱いは今と同じ。打楽器の音も `stop()` で止める。

## 5. 各ゲームの変更

- トップ：`js/top-bgm.js` の `Ailand.top.BGM_SCORE` を §2 の曲に差し替える。
- ぽとん4：`games/drop4/js/sounds.js` の `G.Sounds.NORMAL` を差し替える。終盤のテンポは `games/drop4/js/ui.js` の `ENDGAME_BPM` を 150 → 126 にする。
- オセロっち：`games/othello/js/audio/othello-bgm.js` の `O.BGM_SCORE` を差し替える。`BgmLink` は変えない。
- キャラたたき：`games/whack/js/sounds.js` の `G.Sounds.BGM` を差し替え、`FINAL_BPM` を 168 → 180 にする。
- 各ファイルの先頭のコメント（曲名・調・テンポの説明）も新しい曲に合わせて書き直す。

## 6. テスト

- `tests/core/bgm.test.js`：§4 の項目ごとに、省略時は今と同じになること、`swing` で裏拍の音だけが遅れること、和音の配列、`drums` の音が返ることを確かめる。
- `tests/core/bgm-scores.test.js`：4曲すべてを対象にする。
  - 各声部の長さがそろっている（32拍、オセロっちは48拍）。
  - 音の高さのルール（§3）。
  - 4曲がちがうこと：テンポがすべてちがう、メロディの音色がすべてちがう、そのうえでどの2曲もリズムの型（拍子の長さ・スイング・打楽器の有無と並び）で1つ以上ちがう。
  - ぽとん4の `ENDGAME_BPM` とキャラたたきの `FINAL_BPM` が、ふだんのテンポより速い。
- `scripts\run.bat test` と `scripts\run.bat check` が通る。オセロっちの `scripts\run.bat replay-othello` が golden と一致する。
- 聞こえ方（4曲が出だしで聞き分けられる・楽しい・うるさくない・終盤のテンポ）の確認は、ユーザーの手動テスト。

## 7. 実装者にまかせること

- `core/bgm.js` の中の書き方（曲げ・きらっと音の作り方、スイングした位置の項目名など）。
- 打楽器の音の細かい形。ただし音量の比率は §4 を守る。
- 手動テストで「うるさい」「小さい」と言われたときの音量の微調整。
